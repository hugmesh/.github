# HugMesh

A self-hosted community mesh: chat, forums, video, a wiki and games, on hardware your community runs itself.

- **Website and documentation:** [hugmesh.net](https://hugmesh.net) (also at [hugmesh.github.io](https://hugmesh.github.io))
- **Downloads (beta):** [hugmesh.net/downloads](https://hugmesh.net/downloads)
- **Writing about HugMesh:** [MARKETING.md](https://github.com/hugmesh/.github/blob/main/MARKETING.md)
- **Reporting a security issue:** [SECURITY.md](https://github.com/hugmesh/.github/blob/main/SECURITY.md)

HugMesh is in beta.
